# Historical experiment only

These 4,789 samples and their report belong to the original Iberian experiment.
They lack the observation-quality, availability and split protections required for
the corrected next run. Do not feed these NPZ shards to `tools.next_run.train`.

See [limitations](../../docs/growth-baselines-AP.md) and the
[corrected pipeline](../../tools/next_run/README.md). The files are retained for audit;
new training uses separately rebuilt, checksummed NPY event directories.
